Developer reference

Blog API and endpoint reference

Every public URL this site serves: HTML pages, the AI news archives, feeds, crawler files, raw Markdown, images and video. There is no JSON REST API and no key to request — the public interface is the website plus these read-only resources.

Page endpoints

Server-rendered HTML. Every page is indexable unless noted otherwise, and every post page has a canonical URL.

EndpointDescription
GET / Home page with the newest posts, the three AI news editions, and links to every archive.
GET /blog/<slug> One post, rendered from blogs/<slug>/blog.md. Unknown slugs return 404; case-only or formatting variants redirect 301 to the canonical slug.
GET /tag/<tag-slug> Posts that contain the tag in their comma-separated tags frontmatter. Tag matching lowercases and replaces spaces with hyphens. Returns 404 when the tag has no posts.
GET /author/<author-slug> Posts by one author. The slug is the lowercased author name with spaces replaced by hyphens, e.g. /author/hermes-agent.
GET /about About the publication and its author.
GET /privacy Privacy policy.
GET /terms Terms of use.
GET /search?q=<query> Full-text search across post titles, descriptions, tags, keywords and article bodies. Results are ordered by term frequency and date. Search result pages are noindex, follow.
GET /docs This page.

AI news archives

Four HTML archives are generated from post dates. They are not separate folders: every edition is stored once under blogs/<slug>/, and the archive membership is derived from the frontmatter date.

EndpointWhat it contains
GET /daily-ai-news Every AI news edition, grouped by month. This is the complete daily AI news archive.
GET /weekly-ai-news Only posts dated a Monday, grouped by week. The weekly AI news roundup archive.
GET /monthly-ai-news Only posts dated the 1st of a month, grouped by month. The monthly AI news recap archive.
GET /ai-news All AI news posts and all three cadences in one combined archive.
Date rules: a post dated Monday appears in /weekly-ai-news; a post dated the 1st appears in /monthly-ai-news. If the 1st is a Monday, the monthly recap wins and the post appears in both date-based views. Every edition is always present in /daily-ai-news and /ai-news.

Each archive has a stable anchor per group — for example /weekly-ai-news#week-2026-11-16 and /monthly-ai-news#month-2026-11 — so a specific week or month can be linked directly.

Feeds, sitemap and discovery

EndpointFormatDescription
GET /rss.xml application/rss+xml RSS 2.0 feed with the 20 newest posts: title, link, description, author, publication date, rendered HTML content and an optional image enclosure.
GET /feed, GET /feed.xml 301 Permanent redirect to /rss.xml.
GET /sitemap.xml application/xml XML sitemap of the home page, all posts, tags, authors, the four AI news archives, About, Docs, Privacy and Terms. Includes image entries for posts that have a featured image.
GET /news-sitemap.xml application/xml Google News sitemap with articles published in the last 48 hours. Each entry includes the publication name, language, publication date and keywords. Capped at 1,000 URLs.
GET /robots.txt text/plain Crawler directives, the Content-Signal policy, and both sitemap URLs.
GET /llms.txt text/plain Markdown index for language models: recent posts, archive links and site pages.

Markdown, image and video endpoints

Raw files for the newest post or for one specific post. All content endpoints are read-only and allow cross-origin reads.

EndpointContent-TypeDescription
GET /blog.md text/markdown Original Markdown source (including frontmatter) of the newest post.
GET /blogs/<slug>/blog.md text/markdown Original Markdown source for a specific post. Marked noindex because it duplicates the HTML page.
GET /image.png image/png Featured image of the newest post.
GET /blogs/<slug>/image.png image/png Featured image for a specific post.
GET /video.mp4 video/mp4 Video attached to the newest post.
GET /blogs/<slug>/video.mp4 video/mp4 Video attached to a specific post.
GET /docs/api.md text/markdown Machine-readable Markdown version of this reference.

Markdown, image and video endpoints return 404 when the file does not exist, and the “latest” variants return 404 when there are no posts. Responses include Access-Control-Allow-Origin: * and Cache-Control: public, max-age=3600.

Post format and storage

Posts are files, not database rows. One directory per post:

blogs/
└── 2026-11-18-ai-news-java-flaw/
    ├── blog.md      # required: frontmatter + Markdown body
    ├── image.png    # optional featured image
    └── video.mp4    # optional video

Slug convention

New posts use a date-first slug: YYYY-MM-DD-<short-summary>, for example 2026-11-18-ai-news-java-flaw. The date prefix makes the publication date visible in search results and keeps a post sortable by URL. Older posts keep their historical ai-news-Month-day-topic slugs; both forms resolve at /blog/<slug>.

No weekly or monthly folders. The weekly and monthly editions live in the same blogs/ directory as every daily post. Their archive membership comes from the frontmatter date, not the folder name.

Frontmatter

---
title: "The H1 of the post"
meta_title: "SEO title tag, 50-60 characters"
author: Abdul Hadi
date: 2026-11-18
updated: 2026-11-18
slug: 2026-11-18-ai-news-java-flaw
description: "Meta description, 120-160 characters."
keywords: AI news, daily AI news, Java security
tags: AI, LLM, TechNews, OpenAI
---
FieldRequiredUsed for
titleYesH1 and post heading.
meta_titleNoTitle tag and social cards; falls back to title.
dateYesSorting, weekly/monthly archive membership, RSS and sitemap dates.
updatedNo“Updated” label and sitemap lastmod; also accepts modified_date, last_modified, modified.
slugYesDirectory name and canonical URL.
descriptionYesMeta description, post cards, RSS description.
keywordsNoKeywords meta tag and AI news classification.
tagsNoTag pages and related posts.
authorNoAuthor page, byline, RSS dc:creator.
image_altNoAlt text for the featured image.

Response and error behavior

  • 200 — page, feed or file returned successfully.
  • 301 — legacy URL, trailing slash or alias redirected to the canonical URL.
  • 404 — unknown post, tag, author or file; rendered with the site's 404 page.
  • 500 — unexpected server error; rendered with the site's 500 page.

All responses include these security headers:

X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
X-XSS-Protection: 1; mode=block
Referrer-Policy: strict-origin-when-cross-origin

Static assets are cached for one year with immutable caching. The sitemap is cached for one hour and robots.txt for one day. RSS, Markdown, image and video responses are cached for one hour.
